Sources & acknowledgements

Worth the Fork is a student project by Leyla Karamehmet. ChatGPT assisted with restaurant descriptions.

Map & technology

  • Leaflet 1.9.4: interactive map library (BSD 2-Clause license). Loaded from unpkg.
  • OpenStreetMap contributors: map data and standard tiles. Map data is available under the ODbL; attribution remains visible on the map.
  • OpenStreetMap tile usage policy. This prototype uses standard tiles for a small personal project; larger usage would need a suitable provider.
  • GitHub Pages: intended static hosting.

Privacy

Saved places are stored in this browser’s local storage. There are no accounts, analytics, or server-side saved lists. Map requests are sent to unpkg and OpenStreetMap; external navigation links open Google Maps. No location permission is requested.
